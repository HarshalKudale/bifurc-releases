**Bifurc is a desktop API development workspace for localhost routing, traffic capture, mocking, protocol
testing and git-backed configuration.**

> **This repository does not contain source code.** It only hosts the downloadable builds of Bifurc and its
> issue tracker. The "Source code" archives GitHub adds to every release are empty apart from this README.

## Download

Get the latest build from the **[Releases page](https://github.com/HarshalKudale/bifurc-releases/releases/latest)**.

| Platform | Package | Notes |
| --- | --- | --- |
| Windows 10 / 11 | `Bifurc-<version>-setup.exe` | Installer |
| Windows 10 / 11 | `Bifurc-<version>-win-x64.zip` | Portable, nothing is installed |
| Linux (Debian, Ubuntu) | `bifurc_<version>_<arch>.deb` | `sudo apt install ./bifurc_<version>_<arch>.deb` |
| Linux (any) | `Bifurc-<version>-<arch>.AppImage` | `chmod +x` it, then run it |
| Linux (any) | `Bifurc-<version>-linux-<arch>.tar.gz` | The app as a plain folder |

### Microsoft Store

The Store build installs and updates itself, with no admin prompt.

[**Get it from the Microsoft Store**](https://apps.microsoft.com/detail/9ncb4fdzzqpv)

### Browser extension

The optional companion pairs your browser with the desktop app: proxy toggle, DevTools capture and one-click
mocks.

[**Add Bifurc Companion to Chrome**](https://chromewebstore.google.com/detail/bifurc-companion/dcifgipphabedoiemccjpocgiganpjhi)

## Report a bug or ask for something

Use the **[issue tracker](https://github.com/HarshalKudale/bifurc-releases/issues/new/choose)**. For a bug,
please include:

- your Bifurc version and operating system
- what you did, what you expected, and what happened instead
- logs or screenshots, with anything private removed

Before opening one, have a look at the [open issues](https://github.com/HarshalKudale/bifurc-releases/issues)
in case it is already reported.
